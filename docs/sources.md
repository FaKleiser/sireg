`sources` is an ordered array. Combine entries to cover routes from several sitemaps or add critical pages to a curated suite. All discovered URLs reach the same transformation and selection pipeline, so a sample can omit entries from any source.

## Sitemap

Use a sitemap when the published site already has a route inventory. A production sitemap is a useful baseline for a preview because it includes pages visitors can reach today, even if the preview accidentally drops them. Use a built sitemap if the goal is to check routes newly generated by the current build.

~~~json
{
  "sources": [
    { "type": "sitemap", "url": "https://example.com/sitemap.xml" },
    { "type": "sitemap", "path": "public/sitemap.xml.gz", "maxDepth": 2 }
  ]
}
~~~

| Field | Meaning |
| --- | --- |
| `type` | Use `"sitemap"`. |
| `url` | Hosted sitemap URL. If both `url` and `path` are set, `url` takes precedence. |
| `path` | Local sitemap path, relative to the [configuration directory or `cwd`](configuration.md#path-resolution). |
| `maxDepth` | Maximum sitemap-index depth, default `8`. The root is depth zero. Descending beyond the limit fails the run. |

Sitemap indexes are followed recursively. Relative child locations resolve against the sitemap that contains them. Point to an XML or gzip-compressed sitemap file by using the full sitemap URL or path.

## URL file

Use a file when you want a stable list of pages that must pass every run. The `path` field accepts a local path or an HTTP(S) URL to a text file.

~~~json
{ "sources": [{ "type": "file", "path": "critical-urls.txt" }] }
~~~

Put one complete HTTP(S) URL per line. Blank lines and lines beginning with `#` are ignored after trimming whitespace. For guaranteed coverage, use a separate full run for these pages if your main suite samples URLs.

## Individual URLs

Use `type: "url"` with a `url` field for a handful of health checks or pages absent from a sitemap.

~~~json
{ "sources": [{ "type": "url", "url": "https://example.com/about/" }] }
~~~

## String shorthand

A string ending in `.xml` or `.xml.gz` is inferred as a sitemap. Other HTTP(S) strings are checked as individual URLs. Remaining strings are read as file paths. Use an explicit source object for a sitemap served at a URL without an XML extension or for a hosted URL list.
